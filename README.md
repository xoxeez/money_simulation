# 소학행 자산 플래너 v2

기존 소학행 자산 플래너를 대체할 수 있는 복사 가능한 PWA 소스입니다. 화면은 vanilla JS로 동작하며, 기존 `coupleV8` 데이터와 월별 `closed` 상태를 읽어옵니다.

## 복사할 파일

다음 파일을 기존 웹페이지 폴더에 복사하세요.

```text
index.html
app.js
domain.mjs
styles.css
manifest.json
sw.js
firebase-config.js
```

기존 아이콘 파일(`icon-192.png`, `icon-512.png`, `favicon-32.png`)은 그대로 사용하면 됩니다.

## Firebase 사용

`firebase-config.js`에는 Firebase 프로젝트 설정과 Firestore 문서 경로가 들어 있습니다. 설정 파일은 이전 앱과의 호환을 위해 기존 `firebaseConfig` 및 `DOC_PATH` 바인딩을 유지하면서, 새 앱이 사용하는 `window.firebaseConfig`와 `window.DOC_PATH`에도 값을 노출합니다. 다른 Firebase 프로젝트를 사용할 경우 이 파일의 설정과 문서 경로를 함께 바꾸세요.

Firebase 설정이 없으면 자동으로 localStorage 모드로 동작합니다. 기존 데이터는 다음 순서로 확인합니다.

1. `sohakPlannerV2`
2. `coupleV8`
3. `coupleV7`

기존 `coupleV8` 또는 `coupleV7` 데이터는 새 구조로 마이그레이션됩니다. Firebase에서 읽은 원본 문서는 `sohakPlannerV2:cloudBackup`, 구형 로컬 데이터는 `sohakPlannerV2:localBackup`에 최초 로드 시 보관하고, 변환된 데이터는 `sohakPlannerV2`에 저장합니다. 구형 단일 월 형식과 월별 장부 형식을 모두 읽으며, 변환된 월·계좌·카드·대출·목표·수입·지출·카드 내역·이체 건수를 거래 화면에서 확인할 수 있습니다.

상단의 `백업` 버튼은 현재 데이터와 보관된 원본 스냅샷을 JSON 파일로 저장합니다. `복원` 버튼은 새 백업 파일과 기존 형식의 JSON 파일을 모두 읽습니다.

## 용돈 카드 설정

자산 화면에서 카드의 자금 성격을 지정합니다.

- `관리 계좌`: 개인 지출 시 연결 계좌로 정산 항목 생성
- `비공개 용돈`: 용돈 주인의 개인 지출을 용돈으로 처리
- `외부 계좌`: 잔액을 관리하지 않고 결제 수단만 기록

비공개 용돈 계좌의 잔액과 거래 내역은 화면에 표시하지 않습니다.

## 수입·지출·이체 기록

거래 화면에서 수입, 지출, 계좌 이체를 1회성 또는 매월 정기 항목으로 등록할 수 있습니다. 정기 항목은 시작 월부터 월별 화면에 예정으로 표시되고, 해당 월에 실제 발생했을 때 실제 금액으로 완료 처리하거나 발생하지 않은 달은 건너뛸 수 있습니다. 완료된 정기 지출만 실제 지출 합계에 반영해 예정액과 중복 집계하지 않습니다. 정기 항목을 수정하면 선택한 월부터 새 규칙이 적용되고, 삭제도 선택한 월 이후의 반복만 종료해 앞선 월 기록은 유지합니다. 개별 거래를 눌러 수정하거나 삭제할 수 있고, 실제 카드 지출은 기존 정산 검토 흐름과 연결됩니다.

거래 목록은 전체, 정기 수입, 정기 지출, 비정기 수입, 비정기 지출, 계좌 이체 탭으로 분리됩니다. 탭별 해당 월 거래 건수와 선택 필터의 합계를 확인할 수 있으며, 사용자·정산 필터를 함께 적용할 수 있습니다. 정산 화면에서 개인 카드 사용 항목을 `이체 필요`로 분류하면 `용돈 이체 기록`으로 출금 계좌와 카드 결제 계좌 사이의 실제 이체 내역을 등록할 수 있습니다. 이체 금액이 정산 금액과 같고 목적 계좌가 일치할 때만 정산 완료로 연결됩니다. 출금 계좌는 실제 용돈 계좌인지 저장 전에 확인하세요.

## 대출·차용 관리

자산 화면에서 대출 원금, 명의, 출금 계좌, 첫 상환일, 상환일과 상환 방식을 등록·수정할 수 있습니다. 원리금균등, 원금균등, 매월 이자 납부 후 만기 원금 상환, 만기 이자 일괄 납부, 원리금 체증식, 월별 원금·이자 직접 입력을 지원합니다. 변동금리 적용 회차와 금리, 거치기간, 중도상환 계획도 입력할 수 있으며 미리보기와 상환 일정에서 월별 원금·이자·잔여 원금을 확인할 수 있습니다.

상환 일정의 각 회차에서 실제 납부 원금과 이자, 납부일, 출금 계좌를 기록하거나 수정·삭제할 수 있습니다. 실제 납부는 거래 화면의 `정기 지출` 탭과 월 지출 분석에 대출 상환 항목으로 포함되고, 월 마감에는 예정액과 실제 기록 건수·금액을 함께 저장합니다. 계좌 잔액은 현재 잔액 스냅샷이므로 대출 납부 기록만으로 자동 차감하지 않습니다.

기존 월별 장부의 수입·지출·이체 배열은 계속 읽고, 새로 추가한 반복 규칙은 `cashflowRules`에 별도로 저장합니다. 계좌 잔액은 현재 잔액 스냅샷으로 유지하며, 거래나 이체를 등록해도 자동으로 잔액을 다시 계산하지 않습니다.

## 과거 데이터 처리

- 마감되지 않은 과거 월: 개인 카드 사용을 정산 검토 목록에 추가합니다.
- 마감 완료 월: 기존 월의 결과를 `closeSnapshot`으로 보존하고 새 정산 규칙을 적용하지 않습니다.
- 과거 정산 항목의 초기 상태는 `검토 필요`입니다. 실제로 이체했다면 `이체 완료`로 바꾸세요.

마감 월을 수정하려면 정산 화면에서 먼저 마감을 해제해야 합니다.

## 실행

PWA와 ES module은 `file://` 주소에서 정상 동작하지 않을 수 있으므로 정적 서버로 실행하세요.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/outputs/sohak-planner-v2/`을 열거나, 이 폴더의 파일을 정적 호스팅 루트에 복사해 사용하면 됩니다.

## 배포 후 갱신

`app.js`, `domain.mjs`, `styles.css`를 변경할 때마다 `sw.js`의 `CACHE` 값을 올리세요.

```js
const CACHE = "sohak-planner-v8";
```

이렇게 해야 이미 설치된 PWA가 새 앱 셸을 받아옵니다.
