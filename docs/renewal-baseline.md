# 자산 관리 리뉴얼 기준선

## 목표

두 사람이 함께 사는 가구의 자산, 현금 흐름, 생활비, 개인 정산을 한 곳에서 관리한다. 과거 기록을 그대로 이어가면서 매일 입력은 빠르게, 월말 확인은 빠짐없이 할 수 있어야 한다.

## 기존 기능과 유지할 신규 기능

| 영역 | 2026-09-22 이전 소스의 기능 | 현재 소스에서 이어갈 기능 |
| --- | --- | --- |
| 가계부 | 월별 장부, 월 고정 수입·지출, 기타 1회성·반복 수입·지출, 카드 내역, 계좌 이체 | 빠른 지출 등록, 월별 기록 보기, 사용 목적 분류 |
| 카드·정산 | 카드와 출금 계좌 연결, 카드 내역과 계좌 잔액 추정 | 관리 계좌·용돈·외부 카드 구분, 개인 지출 정산 검토 목록 |
| 대출 | 대출별 상환 방식, 변동금리, 거치, 체증, 중도상환, 직접 입력한 회차별 원금·이자 | 자산 화면과 월마감 흐름에 대출 연결 |
| 자산·계획 | 계좌, 투자 계좌, 기준일 잔액, 캘린더, 예정 현금 흐름, 주택·목표 관리 | 주택 자금 시뮬레이션, 목표, 자산 구성 분석 |
| 검토·보존 | 월마감과 마감 취소 | 정산 상태, 마감 스냅샷, 마감 월 읽기 전용, 과거 사용자 표기 검토 |

현재 화면의 빠른 지출 폼만으로는 정기 수입·지출, 이체, 대출 상환을 충분히 관리할 수 없다. 이 항목들을 단계적으로 다시 추가하면서, 반복 규칙과 실제 거래를 구분하고 기존 분석·정산·마감 기능과 연결한다.

## 회계 처리 기준

- 거래에는 사용 목적, 실제 결제 수단, 결제 대금이 빠져나가는 계좌, 정산 책임자를 각각 기록한다.
- 카드 구매는 구매일의 지출이다. 카드 대금 납부는 출금일의 현금 흐름이며 지출로 다시 합산하지 않는다.
- 개인 용도의 관리 카드 지출은 정산 대상이 될 수 있다. 정산 이체는 계좌 간 이동으로 기록하고 지출에 중복 포함하지 않는다.
- 대출 납부는 원금, 이자, 총 출금액을 분리한다. 이자는 비용이고 원금은 부채 감소다.
- 반복 규칙은 예정 내역을 만들고, 실제 발생 내역과 연결한다. 예정과 실제를 동시에 지출로 계산하지 않는다.
- 과거 사용자를 확정할 근거가 없으면 공동으로 단정하지 않고 확인 필요로 표시한다.
- 마감 스냅샷은 이후 거래·카드 설정 변경에 영향을 받지 않는다. 마감 해제와 재마감은 이력을 남긴다.

## 단계별 구현과 완료 기준

### 0. 데이터 보호와 이전 형식 수용

- `coupleV8`, `coupleV7`, 기존 월별 장부, 구형 단일 월 장부를 모두 읽는다.
- 월 목록과 장부 키를 합쳐 과거 월을 빠뜨리지 않는다. 월 형식이 맞지 않는 장부도 감사 데이터에 보존한다.
- 마이그레이션 전 로컬 또는 Firestore 원본을 브라우저 백업에 보관한다.
- 새 백업 파일은 현재 데이터와 원본 스냅샷을 함께 담고, 기존 JSON 백업 파일도 계속 복원할 수 있게 한다.
- 변환된 월·계좌·카드·대출·목표·수입·지출·카드 내역·이체 건수를 사용자에게 보여주고 확인할 수 있게 한다.

### 1. 반복·비정기 거래와 빠른 입력

- 월 고정 지출·수입, 기타 반복·1회성 항목, 수동 계좌 이체를 편집할 수 있다.
- 최근 입력과 즐겨찾기 템플릿을 빠른 등록에서 쓸 수 있다.
- 반복 규칙의 예정일·금액 변경이 이번 회차만인지 다음 회차부터인지 명확하게 선택한다.
- 예정 내역을 실제 거래로 확정하거나 건너뛸 수 있고, 중복 집계를 막는다.

### 2. 카드 결제와 개인 정산

- 카드 소유자, 카드 이용자, 카드 종류, 결제 계좌, 결제일을 구분한다.
- 개인 용도의 공동/관리 카드 구매에서 적절한 용돈 계좌와 카드 결제 계좌 간 이체를 만들고 완료 여부를 확인한다.
- 신용카드 구매월과 대금 출금월을 각각 보여준다.

### 3. 대출 상환과 월별 현금 흐름

- 과거 상환 방식과 월별 원금·이자 계산을 되살린다.
- 예정 상환액, 실제 납부액, 출금 계좌, 잔여 원금을 월별로 비교한다.
- 계좌 잔액 예측과 캘린더에 카드 대금·대출 납부·반복 거래를 반영한다.

### 4. 공동 월마감과 분석

- 반복 예정 대비 실제, 카드 대금, 대출, 계좌 잔액, 정산 대기를 한 체크리스트에서 확인한다.
- 두 사람이 월마감을 검토하고 스냅샷을 확정한다.
- 자산·부채 추이, 지출 카테고리, 개인/공동 부담 분석은 거래 상세와 연결한다.

## 동시 사용 안전성

두 사용자가 같은 데이터를 함께 편집할 수 있어야 한다. 저장 시 전체 문서를 서로 덮어쓰지 않도록 변경 단위 저장이나 충돌 감지를 갖추고, 오프라인 변경과 복구 가능한 백업을 별도 기준으로 검토한다.
